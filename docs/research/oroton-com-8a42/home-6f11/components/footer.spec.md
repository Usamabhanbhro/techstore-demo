# Footer Specification

## Overview

- Target file: `client/src/components/sites/oroton-com-8a42/home-6f11/OrotonFooter.tsx`
- Interaction model: newsletter validation and mobile disclosure accordions.

## DOM structure

Dark newsletter band with heading, input, submit button, then dark footer grid with social links, customer-service links, and region/legal details.

## Exact style direction

Charcoal background `#161616`, warm-white text, thin separators, small uppercase labels. Newsletter field is transparent with a bottom border rather than a rounded card.

## Text content

Heading: `BE THE FIRST TO KNOW`. Supporting line: `Receive first access to new arrivals and updates on all the latest trends.` Footer links include `Instagram`, `Facebook`, `Journal`, `Contact`, `Shipping & Returns`, and `Privacy`.

## Responsive behavior

Desktop uses a three-column footer. Mobile stacks columns and turns groups into disclosure buttons.
