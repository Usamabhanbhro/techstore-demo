# Hero Specification

## Overview

- Target file: `client/src/components/sites/oroton-com-8a42/home-6f11/OrotonHero.tsx`
- Interaction model: static editorial image with hover-driven CTA underline.

## DOM structure

`section.hero` contains a media wrapper with image and darkening overlay, then an absolutely positioned text lockup with eyebrow, serif title, descriptive line, and a text link.

## Exact style direction

Full-bleed image, 68–74vh on desktop and 82svh on mobile. White typography for a low-key campaign image. The headline is 72px desktop and 44px mobile with tight line-height and normal letter spacing.

## Text content

Eyebrow: `SPRING 25`. Title: `UNCHARTED BEAUTY`. Description: `Rich in texture. Defined by detail.` CTA: `DISCOVER MORE`.

## Responsive behavior

Desktop text sits on the lower-left with generous inset. Mobile text is lower-left with narrower measure and a darker gradient to preserve contrast.
