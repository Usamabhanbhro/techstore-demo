# Visual QA Record

The local implementation was reviewed at desktop size `1440x900` and mobile size `390x844` using the managed live preview. The desktop frame renders the sale strip, sticky navigation, image-led hero, three editorial link panels, four-card product rail, campaign split panel, editorial grid, newsletter, and dark footer without overflow. The mobile frame collapses the header into a compact wordmark/menu treatment, stacks the editorial modules, presents the product rail as a horizontal scroller, and switches footer groups to accordion-ready rows.

The source site’s native logo asset is reachable at `https://cdn11.bigcommerce.com/s-hyjjuz0fve/images/stencil/original/content/homepage/logo.png`. The reference environment could not resolve `images.unsplash.com`, so the clone uses reachable Pexels fashion imagery for the hero and editorial surfaces; these image hosts rendered in the local preview and preserve the intended warm, editorial merchandising tone.

The implementation uses `Playfair Display` for the display serif and `DM Sans` for navigation, metadata, and body copy. The visual system follows the reference evidence: near-white canvas, charcoal utility chrome, low-radius editorial panels, thin rules, uppercase microcopy, and image-led asymmetry. Motion is limited to restrained hover zooms, link tracking, sticky-header shadow, and reduced-motion fallbacks.
